## Get Up and Running

<Steps>
  <Step title="Create your account">
    Sign up at [app.goodboyrobot.com](https://app.goodboyrobot.com) and confirm your email. Your workspace is ready instantly — no credit card required to start.
  </Step>
  <Step title="Generate an API key">
    Head to **Settings → API Keys** in your dashboard and click **New Key**. Copy the key — you'll use it to authenticate every API request.
  </Step>
  <Step title="Make your first command call">
    Send your first request to the Commands API and watch GoodBoyRobot fetch, wag, and deliver.

    ```bash
    curl -X POST https://api.goodboyrobot.com/v1/commands/execute \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"command": "fetch", "payload": {"message": "Hello, world!"}}'
    ```
  </Step>
  <Step title="Connect an integration">
    Visit **Integrations** in the sidebar and connect Slack, GitHub, or any supported service to start routing events automatically.
  </Step>
</Steps>
