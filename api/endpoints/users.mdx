The Users API gives you programmatic access to the profile associated with your API key. Use it to fetch your account details — including your plan and personal settings — or to keep your display name and preferences in sync with your own systems without opening the dashboard.

---

## GET /api/v1/users/me

Return the full profile for the currently authenticated user. The response includes account information, your active plan, and any workspace settings you have configured.

### Example Request

```bash
curl https://api.goodboyrobot.com/api/v1/users/me \
  --request GET \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: application/json"
```

### Example Response

```json
{
  "id": "usr_01hxzep8u5abcdef",
  "email": "ada@acme-corp.example.com",
  "name": "Ada Lovelace",
  "plan": "pro",
  "created_at": "2024-01-15T08:30:00.000Z",
  "settings": {
    "timezone": "America/New_York",
    "notifications_email": true,
    "default_timeout": 30
  }
}
```

### Response Fields

<ResponseField name="id" type="string">
  The unique identifier for your user account, prefixed with `usr_`.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with your GoodBoyRobot account. This field is read-only and cannot be changed via the API.
</ResponseField>

<ResponseField name="name" type="string">
  Your display name as it appears in the dashboard and in notifications sent by Byte.
</ResponseField>

<ResponseField name="plan" type="string">
  Your current subscription plan. One of `free`, `pro`, or `enterprise`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when your account was created.
</ResponseField>

<ResponseField name="settings" type="object">
  Your personal workspace preferences.

  <Expandable title="Settings fields">
    <ResponseField name="settings.timezone" type="string">
      Your preferred IANA timezone string, used when formatting timestamps in notifications and reports.
    </ResponseField>
    <ResponseField name="settings.notifications_email" type="boolean">
      Whether GoodBoyRobot sends email notifications for command completions and errors.
    </ResponseField>
    <ResponseField name="settings.default_timeout" type="integer">
      The default timeout in seconds applied to command executions when no `options.timeout` is specified.
    </ResponseField>
  </Expandable>
</ResponseField>

## PATCH /api/v1/users/me

Update your display name, workspace settings, or both. Only the fields you include in the request body are modified — all other profile fields remain unchanged. The endpoint returns your complete updated profile on success.

### Body Parameters

<ParamField body="name" type="string">
  Your new display name. Must be between 1 and 100 characters.
</ParamField>

<ParamField body="settings" type="object">
  A partial settings object. Only the keys you include are updated — unspecified settings keys are left as-is.

  <Expandable title="Updatable settings fields">
    <ParamField body="settings.timezone" type="string">
      A valid IANA timezone string, such as `"America/Chicago"` or `"Europe/Berlin"`. GoodBoyRobot uses this when scheduling and formatting time-based notifications.
    </ParamField>
    <ParamField body="settings.notifications_email" type="boolean">
      Set to `true` to receive email notifications for command events, or `false` to turn them off.
    </ParamField>
    <ParamField body="settings.default_timeout" type="integer">
      The fallback timeout in seconds for command executions. Must be between `5` and `300`.
    </ParamField>
  </Expandable>
</ParamField>

### Example Request

```bash
curl https://api.goodboyrobot.com/api/v1/users/me \
  --request PATCH \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "Ada L.",
    "settings": {
      "timezone": "Europe/London",
      "default_timeout": 60
    }
  }'
```

### Example Response

```json
{
  "id": "usr_01hxzep8u5abcdef",
  "email": "ada@acme-corp.example.com",
  "name": "Ada L.",
  "plan": "pro",
  "created_at": "2024-01-15T08:30:00.000Z",
  "settings": {
    "timezone": "Europe/London",
    "notifications_email": true,
    "default_timeout": 60
  }
}
```

The response mirrors the full profile object from `GET /api/v1/users/me`, reflecting your changes immediately.

<Tip>
  You can update just your settings without touching your name — simply omit the `name` field from the request body. PATCH only applies the keys you send.
</Tip>

<Note>
  Your `email` and `plan` fields cannot be changed through the API. To update your email, visit **Settings → Account** in the GoodBoyRobot dashboard. Plan changes are handled on the **Settings → Billing** page.
</Note>
