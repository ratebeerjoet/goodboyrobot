# Starroute Concept Brief 

### Overview
An explanation of what Starroute is and what it does.

### Market

A breakdown of the kinds of people and organizations Starroute is intended for. Examples include:

* game developers
* sci-fi writers
* astronomers

### Value

A summary of the services Starroute can provide and the kinds of questions it can answer.

### Key Features

An explanation of what the api actually does, which includes:

* Identifying stars
* Plotting theoretical interstellar routes and travel times.
* Naming astronomical features of interest.

### Explicitly out of scope

A summary of several things that this API  project cannot do. For example, it cannot:

* Filter for specific types of stars.
* Go off-map or estimate unknown astronomical positions.


### Open Questions

The visual side: what will this interface look like? Will there be a split screen? How much will the user have to imagine for themselves?
